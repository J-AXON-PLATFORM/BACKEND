# Visión de producto

> **Clasificación:** OBLIGATORIO  
> **Instancia J-AXON:** CKP-JAXON-003 | 2026-09-29.

## Visión

J-AXON es una plataforma de gestión tecnológica para una organización, orientada a inventario de activos, descubrimiento autorizado de red, Collector/Agents, soporte/tickets, asistencia IA/RAG, identidad, automatización/notificaciones y auditoría/reportes, con escenario base on-premise/LAN.

## Resultado deseado de v1

Administrar activos, recibir información técnica por Agents, descubrir dispositivos de forma autorizada, gestionar soporte asociado y ofrecer asistencia IA/RAG con fuentes/trazabilidad y control de acceso. Un QA limpio debe poder ejecutar los flujos E2E aprobados sin depender del legado.

## No objetivos v1 destacados

Microservicios, Kubernetes, SaaS multi-tenant compartido, IA autónoma, shell remota arbitraria, app móvil/escritorio de usuario y BI/BPM avanzado.
