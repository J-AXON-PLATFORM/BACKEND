# Definición de preparado


> **Clasificación:** OBLIGATORIO  
> **Estado:** Plantilla base  
> **Idioma de documentación:** Español  
> **Convención técnica:** Código, nombres de archivos, clases, variables, endpoints y artefactos técnicos en inglés.  
> **Fuente de verdad:** Este documento solo debe duplicar información cuando sea imprescindible; en caso contrario debe enlazar a la fuente canónica.


## Propósito

Evitar iniciar trabajo con historias ambiguas.


Una Historia de Usuario está `READY` cuando:

- Objetivo y valor entendibles.
- Criterios de aceptación verificables.
- Dependencias conocidas.
- Flujos afectados identificados.
- Riesgos relevantes visibles.
- Tamano razonable para el sprint; si no, debe dividirse.
- No existen decisiones bloqueantes sin resolver.
