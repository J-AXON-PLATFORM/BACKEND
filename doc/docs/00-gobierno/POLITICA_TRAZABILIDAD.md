# Política de trazabilidad


> **Clasificación:** OBLIGATORIO  
> **Estado:** Plantilla base  
> **Idioma de documentación:** Español  
> **Convención técnica:** Código, nombres de archivos, clases, variables, endpoints y artefactos técnicos en inglés.  
> **Fuente de verdad:** Este documento solo debe duplicar información cuando sea imprescindible; en caso contrario debe enlazar a la fuente canónica.


## Propósito

Definir el mínimo de trazabilidad exigido.


Cadena recomendada:

`EPIC -> FEAT -> US -> REQ/NFR -> FLOW -> AC -> ADR/RFC (si aplica) -> CODE -> TEST -> PR -> RELEASE`

No todos los nodos son obligatorios para cambios pequeños, pero toda funcionalidad debe poder relacionarse con al menos requisito/HU, criterio de aceptación, código y prueba.
