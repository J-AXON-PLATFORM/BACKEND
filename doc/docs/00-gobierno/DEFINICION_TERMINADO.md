# Definición de terminado

> **Clasificación:** OBLIGATORIO  
> **Estado:** Plantilla dinámica

## Propósito

Definir cuándo un cambio puede considerarse terminado. El proyecto puede añadir criterios, pero no eliminar controles relevantes sin justificarlo.

- [ ] Criterios de aceptación cumplidos.
- [ ] Implementación revisada.
- [ ] TDD o validaciones equivalentes ejecutadas.
- [ ] Integraciones afectadas verificadas.
- [ ] Contratos afectados actualizados y compatibles o con migración aprobada.
- [ ] Regresión relevante comprobada.
- [ ] Flujos y documentación afectados actualizados.
- [ ] Trazabilidad actualizada.
- [ ] NFR afectados verificados cuando aplique.
- [ ] Seguridad/privacidad revisadas cuando aplique.
- [ ] No quedan pruebas deshabilitadas o debilitadas sin justificación aprobada.
- [ ] Criterios de calidad aplicables superados.
- [ ] Riesgos conocidos y deuda técnica aceptada documentados.
- [ ] Existe evidencia suficiente de que el comportamiento afectado funciona como parte del sistema, no solo de forma aislada.
