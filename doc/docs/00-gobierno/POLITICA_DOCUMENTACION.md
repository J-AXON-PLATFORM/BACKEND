# Política de documentación


> **Clasificación:** OBLIGATORIO  
> **Estado:** Plantilla base  
> **Idioma de documentación:** Español  
> **Convención técnica:** Código, nombres de archivos, clases, variables, endpoints y artefactos técnicos en inglés.  
> **Fuente de verdad:** Este documento solo debe duplicar información cuando sea imprescindible; en caso contrario debe enlazar a la fuente canónica.


## Propósito

Mantener documentación útil, pequeña, navegable y sincronizada con el sistema.


## Reglas

- Una fuente canónica por concepto.
- Preferir enlaces a duplicacion.
- Documentos enfocados y pequeños.
- Diagramas como texto cuando sea posible.
- Documentación en español; identificadores técnicos en inglés.
- Todo cambio debe evaluar si modifica requisitos, flujos, arquitectura, contratos o runbooks.
