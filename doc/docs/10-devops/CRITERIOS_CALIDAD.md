# Criterios de calidad DevOps

> **Clasificación:** CONDICIONAL

## Propósito

Definir evidencias necesarias para promover un cambio.

## Posibles controles

- compilación;
- lint;
- unitarias;
- integración;
- contrato;
- seguridad;
- vulnerabilidades;
- SBOM;
- build reproducible;
- smoke;
- migraciones;
- performance;
- aprobación.

## Regla

No usar porcentajes o gates arbitrarios sin relación con riesgo.

Cada gate debe indicar:

- objetivo;
- responsable;
- severidad;
- comportamiento al fallar;
- excepción;
- evidencia.
