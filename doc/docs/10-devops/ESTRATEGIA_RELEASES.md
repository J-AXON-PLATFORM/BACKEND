# Estrategia de releases

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Definir cómo se prepara, valida, publica y verifica una versión.

Considerar:

- versión candidata;
- aprobaciones;
- notas de versión;
- artefactos;
- migraciones;
- compatibilidad;
- despliegue;
- smoke tests;
- observabilidad posterior;
- reversión/contingencia;
- comunicación.
