# Implementaciones específicas de proveedores DevOps

> **Clasificación:** OPCIONAL  

Crear subcarpetas únicamente para proveedores realmente seleccionados, por ejemplo:

```text
providers/
  github-actions/
  gitlab-ci/
  jenkins/
  azure-devops/
```

La estrategia permanece en los documentos superiores; aquí solo vive la implementación específica del proveedor elegido.
