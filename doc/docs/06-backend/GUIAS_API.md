# Guías de API

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Definir convenciones de API sin fijar REST, GraphQL, gRPC u otro estilo hasta que el proyecto lo decida.

Definir según aplique:

- estilo de API;
- versionado;
- nombres;
- schemas;
- paginación/filtros/orden;
- idempotencia;
- autenticación/autorización;
- modelo de errores;
- límites/timeouts;
- deprecación;
- observabilidad;
- especificación canónica;
- pruebas de contrato.
