# Guía operativa

> **Clasificación:** CONDICIONAL

## Propósito

Permitir operar el sistema de forma repetible sin depender de conocimiento oral.

## Contenido

- propietarios;
- dependencias;
- arranque;
- shutdown;
- health;
- despliegue;
- rollback;
- backups;
- restauración;
- tareas programadas;
- rotación de secretos;
- fallos frecuentes;
- diagnóstico;
- escalamiento.

## Procedimiento

Cada runbook debe incluir:

```text
Objetivo:
Precondiciones:
Riesgos:
Pasos:
Verificación:
Rollback:
Cuándo detenerse:
Escalamiento:
```

## Seguridad

No almacenar credenciales reales en el runbook.
