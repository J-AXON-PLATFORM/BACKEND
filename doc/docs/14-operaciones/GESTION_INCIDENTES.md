# Gestión de incidentes

> **Clasificación:** CONDICIONAL

## Propósito

Definir respuesta coordinada ante degradaciones o fallos.

## Severidad

Definir niveles usando:

- impacto;
- usuarios;
- datos;
- seguridad;
- duración;
- función crítica.

## Flujo

```text
Detección
→ triage
→ declaración
→ contención
→ mitigación
→ recuperación
→ verificación
→ cierre
→ postmortem cuando aplique
```

## Roles

Según tamaño:

- incident commander;
- responsable técnico;
- comunicaciones;
- enlace de negocio.

Un equipo pequeño puede combinar roles.

## Comunicación

Definir:

- audiencia;
- frecuencia;
- canal;
- información mínima;
- quién comunica.

## Evidencia

Conservar timeline, decisiones y cambios relevantes.

## Después

Activar `POSTMORTEM.md` según impacto/riesgo.
