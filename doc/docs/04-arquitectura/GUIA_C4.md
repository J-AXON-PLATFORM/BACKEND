# Guía C4

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Usar el modelo C4 como lenguaje visual de arquitectura cuando aporte claridad, sin obligar a producir todos sus niveles.

## Niveles

1. **Contexto del sistema:** usuarios y sistemas externos.
2. **Contenedores:** aplicaciones, servicios, almacenes de datos o unidades desplegables relevantes.
3. **Componentes:** componentes principales dentro de un contenedor cuando el detalle sea útil.
4. **Código:** solo cuando una vista de bajo nivel tenga valor real y pueda mantenerse actualizada.

Preferir Mermaid u otro formato de diagramas como código cuando sea compatible con el proyecto. Evitar diagramas detallados que se conviertan rápidamente en documentación obsoleta.
