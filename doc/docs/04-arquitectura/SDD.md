# Descripción del diseño de software (SDD)

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Describir cómo el diseño satisface requisitos funcionales y no funcionales.

## Contenido sugerido

- drivers de diseño;
- descomposición de módulos/componentes;
- interfaces y contratos;
- diseño de datos;
- manejo de errores;
- concurrencia y consistencia;
- seguridad;
- resiliencia;
- observabilidad;
- capacidad de prueba;
- trazabilidad a requisitos;
- decisiones ADR relacionadas.
