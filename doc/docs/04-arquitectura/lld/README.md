# Diseño de bajo nivel (LLD)

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Crear diseño de bajo nivel únicamente para partes cuya complejidad justifique diseño previo.

Un LLD puede describir:

- clases/componentes;
- algoritmos;
- secuencias;
- transacciones;
- locks/concurrencia;
- contratos;
- invariantes;
- casos límite;
- estrategia de pruebas.

No generar LLD para código trivial.
