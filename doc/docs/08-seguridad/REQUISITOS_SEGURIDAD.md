# Requisitos de seguridad

> **Clasificación:** OBLIGATORIO  
> **Estado:** Plantilla dinámica

## Propósito

Definir requisitos de seguridad verificables según el riesgo real del proyecto.

Evaluar según aplique:

- autenticación;
- autorización;
- protección de datos;
- gestión de sesiones;
- validación de entradas;
- registro y auditoría;
- gestión de secretos;
- seguridad de dependencias;
- abuso, fraude y rate limiting;
- aislamiento entre usuarios/tenants;
- cifrado;
- privacidad y cumplimiento;
- recuperación y continuidad.

Cada requisito importante debe poder vincularse a pruebas o controles verificables.
