# Entornos de prueba

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Definir dónde se ejecuta cada tipo de prueba y cómo se controla el entorno.

Por cada entorno indicar:

- propósito;
- tipos de prueba permitidos;
- responsable;
- estrategia de creación/reset;
- dependencias reales/simuladas;
- política de datos;
- secretos y accesos;
- aislamiento;
- duración/efimeridad;
- diferencias conocidas respecto a producción.
