# Pruebas de accesibilidad

> **Clasificación:** CONDICIONAL

## Activar si

Existe una interfaz humana donde accesibilidad sea relevante; recomendada por defecto para web pública.

## Capas

- análisis automático;
- pruebas de componentes;
- navegación por teclado;
- foco;
- zoom;
- lector de pantalla en flujos críticos;
- contraste;
- contenido dinámico.

## Regla

Las herramientas automáticas detectan una parte de los problemas; no sustituyen validación humana de flujos críticos.
