# Pruebas de seguridad

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Conectar la estrategia de pruebas con requisitos, controles y amenazas relevantes.

No duplicar la política de seguridad. Mapear las pruebas a:

- requisitos de seguridad;
- amenazas del threat model;
- controles implementados;
- fronteras de confianza;
- regresiones históricas.

Elegir técnicas/herramientas según el riesgo del proyecto.
