# Datos de prueba

> **Clasificación:** CONDICIONAL  
> **Estado:** Plantilla dinámica

## Propósito

Definir datos deterministas, representativos y seguros para pruebas.

Considerar:

- datos sintéticos;
- fixtures/factories;
- seeds de QA;
- aislamiento entre pruebas;
- limpieza;
- casos límite;
- volumen representativo;
- anonimización;
- datos sensibles.

Evitar datos personales reales de producción salvo autorización explícita, necesidad justificada y controles adecuados.
