# Convenciones de flujos


> **Clasificación:** OBLIGATORIO  
> **Estado:** Plantilla base  
> **Idioma de documentación:** Español  
> **Convención técnica:** Código, nombres de archivos, clases, variables, endpoints y artefactos técnicos en inglés.  
> **Fuente de verdad:** Este documento solo debe duplicar información cuando sea imprescindible; en caso contrario debe enlazar a la fuente canónica.


## Propósito

Definir como documentar flujos de forma consistente.


## Identificador

`FLOW-<AREA>-NNN`

## Todo flujo debe incluir

- Objetivo.
- Actor/trigger.
- Precondiciones.
- Flujo principal.
- Flujos alternativos.
- Flujos de error.
- Postcondiciones.
- Datos involucrados.
- Módulos involucrados.
- Requisitos and tests.

## Diagramacion

Preferir Mermaid. No incluir detalles técnicos en business flows.
