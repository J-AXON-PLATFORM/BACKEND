# Rendimiento frontend

> **Clasificación:** CONDICIONAL

## Propósito

Definir presupuestos y medición de rendimiento percibido.

## Medir según contexto

- tiempo de carga;
- interactividad;
- renderizado;
- tamaño de bundles;
- imágenes;
- requests;
- memoria;
- tareas largas;
- Core Web Vitals cuando correspondan.

## Estrategias

Evaluar según evidencia:

- code splitting;
- lazy loading;
- prefetch;
- compresión;
- caché;
- optimización de imágenes;
- virtualización;
- memoización;
- reducción de JavaScript.

No optimizar sin medición.
