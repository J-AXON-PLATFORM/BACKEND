# Sistema de diseño

> **Clasificación:** CONDICIONAL

## Propósito

Definir lenguaje visual y componentes compartidos sin obligar a crear una librería compleja.

## Capas

- principios;
- tokens;
- tipografía;
- espaciado;
- iconografía;
- colores;
- componentes;
- patrones;
- contenido/microcopy.

## Tokens

Cuando exista sistema de diseño, preferir tokens semánticos sobre valores dispersos.

## Componentes base

Definir estados, accesibilidad, tamaños y variaciones.

## Gobernanza

- propietario;
- versionado;
- cambios incompatibles;
- documentación;
- pruebas visuales si aportan valor.

## Regla

Para un proyecto pequeño puede ser suficiente una guía mínima. No crear un design system empresarial sin necesidad.
