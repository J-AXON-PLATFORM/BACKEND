# Accesibilidad

> **Clasificación:** CONDICIONAL; recomendada por defecto en interfaces humanas.  
> **Instancia J-AXON:** CKP-JAXON-005 | 2026-09-29.

## Objetivo

**WCAG 2.2 nivel AA como objetivo de diseño para v1**, sin afirmar certificación formal hasta una evaluación específica.

## Diseñar y probar

- navegación por teclado;
- foco visible y orden lógico;
- semántica/labels;
- contraste;
- mensajes de error comprensibles;
- zoom;
- lectores de pantalla en flujos críticos cuando el riesgo lo justifique;
- reducción de movimiento cuando aplique.

## Componentes

Cada interactivo define rol/semántica, nombre accesible, estados, teclado, foco y error.

## Pruebas

Combinar lint/análisis automático, pruebas automatizadas, navegación manual por teclado y revisión con lector de pantalla en journeys importantes. La automatización no demuestra conformidad completa.
