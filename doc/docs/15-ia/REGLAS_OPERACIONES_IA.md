# Reglas de operaciones para IA

> **Clasificación:** CONDICIONAL

## Reglas

- no declarar recuperación sin verificar el resultado;
- no asumir que existe backup porque hay configuración;
- diferenciar RTO/RPO objetivo de RTO/RPO probado;
- no ejecutar acciones destructivas sin autorización;
- registrar evidencia de incidentes y cambios;
- priorizar mitigación segura durante incidentes;
- no ocultar síntomas desactivando alertas sin causa;
- proponer postmortem para incidentes significativos;
- actualizar runbooks cuando cambie operación.
