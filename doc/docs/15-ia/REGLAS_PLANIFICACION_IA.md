# Reglas de planificación para IA

> **Clasificación:** CONDICIONAL

## Reglas

- planificar por resultados;
- seleccionar perfiles técnicos;
- aplicar matriz de activación;
- identificar decisiones pendientes;
- enlazar requisitos, flujos y contratos;
- separar decisiones de implementación;
- incluir datos/migraciones/infraestructura cuando el cambio los afecta;
- indicar prueba y evidencia para cada resultado;
- separar trabajo funcional de cambios destructivos/operativos si reduce riesgo;
- no crear tareas artificialmente pequeñas;
- identificar dependencias entre tareas;
- incluir rollout/rollback cuando el cambio llegue a producción.
