# Reglas de seguridad para IA

> **Clasificación:** CONDICIONAL

## Reglas

- no inventar criptografía;
- no exponer secretos;
- no reducir controles para facilitar desarrollo;
- aplicar mínimo privilegio;
- separar autenticación y autorización;
- validar datos no confiables;
- activar threat model cuando el riesgo lo justifique;
- considerar dependencias y cadena de suministro;
- no deshabilitar scanning sin justificar;
- no introducir datos reales sensibles en QA/dev sin controles;
- acompañar cambios sensibles con pruebas y trazabilidad;
- revisar logging/telemetría para evitar fugas de información.
