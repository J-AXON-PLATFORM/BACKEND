# Adaptadores para IA

La fuente de verdad **no** vive en esta carpeta. Vive principalmente en:

- `PROYECTO_MAESTRO.md`;
- `docs/00-gobierno/CONSTITUCION_IA.md`;
- `docs/00-gobierno/FLUJO_TRABAJO_IA.md`;
- `docs/00-gobierno/MARCO_TOMA_DECISIONES.md`;
- `docs/16-contexto/POLITICA_CONTEXTO_IA.md`.

Crear un adaptador únicamente cuando una herramienta de IA necesite un archivo o formato especial. El adaptador debe ser corto, no duplicar reglas y apuntar a las fuentes canónicas.
