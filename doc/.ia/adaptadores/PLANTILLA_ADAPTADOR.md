# Adaptador para <Herramienta>

Antes de trabajar:

1. Leer `PROYECTO_MAESTRO.md`.
2. Leer `docs/00-gobierno/CONSTITUCION_IA.md`.
3. Seguir `docs/16-contexto/ENRUTADOR_DOCUMENTACION.md` y cargar solo el contexto relevante.
4. Aplicar `MARCO_TOMA_DECISIONES.md` cuando exista una decisión abierta.
5. Permanecer en modo análisis hasta obtener la aprobación requerida.
6. Aplicar TDD o validación apropiada.
7. Actualizar contratos, documentación y trazabilidad afectados antes de declarar terminado.

Este archivo debe contener solo instrucciones necesarias para adaptar la herramienta; no duplicar políticas completas.
