# Manifiesto del framework

> **Versión:** 1.0.0  
> **Nombre:** `doc`  
> **Naturaleza:** framework documental dinámico y reutilizable.

## Cobertura

Esta versión está preparada para combinar, según necesidad:

- backend y APIs;
- frontend web;
- móvil, escritorio y CLI;
- batch/workers;
- monolito y monolito modular;
- microservicios y sistemas distribuidos;
- arquitecturas orientadas a eventos;
- serverless;
- bases de datos, ETL/ELT y gobierno de datos;
- DevOps, CI/CD e infraestructura como código;
- on-premise, cloud, híbrido y multicloud;
- seguridad y cadena de suministro;
- testing funcional y no funcional;
- observabilidad, incidentes, DR y prácticas SRE;
- desarrollo asistido por IA con trazabilidad y control de decisiones.

## Modelo dinámico

El framework usa:

1. perfil documental;
2. perfiles técnicos;
3. matriz de activación;
4. marco de decisiones;
5. validación documental automática.

La existencia de una plantilla no obliga a usar la tecnología o patrón asociado.

## Instancia de proyecto J-AXON

Se conserva el framework 1.0.0. CKP-JAXON-005 consolida decisiones de la instancia hasta el Lote 54 y deja el proyecto `DESIGN_READY`, sin cambiar la versión genérica ni autorizar implementación general. La continuidad de la instancia registra después incrementos expresamente autorizados hasta `AC-JAXON-093` sin alterar el framework genérico. Para evitar confundir la plantilla con artefactos conversacionales, `CHECKPOINT_JAXON.md`, `CONTROL_CAMBIOS_CHECKPOINT.md` e `INVENTARIO_ARCHIVOS_CHECKPOINT.json` ya no se incluyen dentro de `doc/`; el checkpoint se distribuye externamente. `docs/16-contexto/` sí se conserva porque es parte del mecanismo reutilizable de contexto dinámico del framework.
